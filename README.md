# Auto Clicker

A simple auto clicker for Windows.

## How to use

1. Click **Auto Clicker Char screen.exe**, then click the download button.
2. Double-click the file to run it.
3. Press **Q** to turn auto clicking **on**.
4. Press **Q** again to turn it **off**.

## Note

Windows may show a "Windows protected your PC" warning the first time you run it. This is normal for small programs that aren't from a big publisher. If you trust it, click **More info**, then **Run anyway**.
